# 🤖 GitBot

[PL] **GitBot** to bot Discorda stworzony w Pythonie (`discord.py`), który pozwala na szybkie przeglądanie profilów oraz repozytoriów użytkowników serwisu GitHub bezpośrednio z poziomu czatu.

[EN] **GitBot** is a Discord bot built with Python (`discord.py`) that allows users to quickly inspect GitHub profiles and repositories directly from Discord.

---

## 🇵🇱 Wersja Polska

### 🚀 Funkcje
* **`/profile [username]`** — Wyświetla statystyki profilu, opis (bio), liczbę obserwujących oraz najpopularniejsze repozytorium.
* **`/repos [username]`** — Pokazuje listę 5 najnowszych publicznych projektów wraz z liczbą gwiazdek i forków.
* **`/help`** — Wyświetla menu pomocy z opisem wszystkich dostępnych komend.

### 🛠️ Technologie
* Python 3
* `discord.py`
* GitHub REST API
* Hosting: Render.com (Web Service)
